# PDFSim

PDF 双面打印前的页码编排与装订准备工具（桌面应用，PySide6 + pikepdf + PyMuPDF）。

## 功能

- **自动识别特殊页面**：封面 / 签字页 / 目录 / 正文起始页（关键词 + 书签，可配置）
- **双面打印编排**：自动插入封面背面、签字页背面、A3 背面空白，自动补齐末页
- **从正面开始**：指定页面落在纸张正面，前面自动补空白；A3 大页强制正面
- **页码自动编号**：连续编号、自动跳过"不加页码"页、可选"其他空白页自动编页码"
- **页码位置/样式**：四角 + 自定义偏移、距上/距下、字体/字号/颜色
- **旋转校正**：A4 横向、A3 纵向自动检测并旋转到正确方向（可按页覆盖）
- **模拟书视图**：翻书预览正反面对应关系，缩略图双列自适应 + 平滑滚动
- **多选批量**：多页批量设置属性标签、旋转方向、页码样式
- **打印友好输出**：`原文件名（打印装订）.pdf`，原文件只读不改动

## 快速开始

```bash
pip install -r requirements.txt
# 运行
python -m pdfsim.app          # 或按 src 入口运行
# 测试（全量 336+ 用例）
pytest src/tests
```

## 生成测试样本（可选）

性能/边界测试的大样本可通过脚本再生成：

```bash
python src/tests/samples/gen_samples.py
```

## 打包

```bash
python build.py               # 输出 dist/PDFSim.exe
```
