# PDFSim UI 原型说明（Stage 1）

> **项目**：PDFSim —— Windows 桌面单文件软件
> **阶段**：Stage 1 —— UI 原型说明（仅文字描述，不含示意图/代码）
> **文档状态**：待指导者审查
> **版本**：v1.0（2026-08-26）

本文档对应《Stage1_提示语.md》第十一章"交付物 2"，覆盖：主窗口布局、书视图翻页交互（状态机）、缩略图列表显示规则、全局设置对话框字段、异常提示 UI 表现，以及关键交互流程（文字描述）。

## 1. 主窗口布局

### 1.1 整体结构

主窗口为单文档界面（每次打开一个 PDF），采用**三段式布局**：

```
┌────────────────────────────────────────────────────────────────┐
│ 菜单栏 / 工具栏（打开、自动识别、全局设置、输出）                 │
├──────────────┬─────────────────────────────────────────────────┤
│              │                                                 │
│  ① 左侧面板   │       ② 右侧主视图（"书"视图）                  │
│  （缩略图列表）│       （页面渲染区 + 翻页交互）                  │
│              │                                                 │
│              │                                                 │
├──────────────┴─────────────────────────────────────────────────┤
│  ③ 底部页面配置面板（选中页的属性 / 页码 / 样式 / 重叠警告）      │
└────────────────────────────────────────────────────────────────┘
```

### 1.2 各区域尺寸比例（建议，可随窗口缩放保持相对比例）

| 区域 | 建议占比 | 说明 |
|------|----------|------|
| ① 左侧面板 | 宽约 **18%**（最小 200px，最大 320px） | 缩略图竖排列表，可独立滚动；窄条宽屏友好 |
| ② 书视图 | 其余宽度（约 **62%**，随窗口变化） | 页面渲染居中显示；按页面纵横比自动缩放适配高度 |
| ③ 底部配置面板 | 高约 **26%**（最小 180px） | 横跨左右两区；无选中页时折叠为一条提示栏 |

- 默认窗口：1280×800（可缩放，最小 960×640）。
- 左右分栏可拖动分隔条；底部面板高度固定（不随窗口等比）。
- 布局采用 Qt `QSplitter`（左/右）+ `QVBoxLayout`（主区/底部）实现。

### 1.3 菜单栏 / 工具栏

- 文件：打开 PDF…、重新打开、退出。
- 工具：自动识别书签标记、全局设置…、输出。
- 帮助：关于（版本、依赖说明）。

## 2. 书视图翻页交互（状态机）

### 2.1 视图含义

书视图模拟"装订后的书"，按**物理页面顺序**展示（含自动插入的空白页）。书的每一"面"对应一次双面打印的纸面：正面=奇数位、背面=偶数位。

### 2.2 状态机

书视图存在 3 个状态，由"当前选中页的物理序号"决定：

```
                    ┌─────────────────────────────────────────┐
                    │                                         │
                    ▼                                         │
   ┌────────────┐   选中第 1 页      ┌──────────────────┐      │
   │  合起       │◄───────────────── │  展开-左高亮      │◄─────┤
   │  (Closed)   │                   │  (Open-Left)      │      │
   └────────────┘                   └──────────────────┘      │
         ▲                              ▲          │           │
         │                              │          │ 选中偶数页 │
  选中第 1 页                            │          ▼           │
         │                              │    ┌──────────────────┐
         │                              └────│  展开-右高亮      │
         │  ←（第 1 页唯一）                  │  (Open-Right)     │
         └────────────────────────────────────┴──────────────────┘
```

| 状态 | 触发（选中页物理序号） | 画面表现 |
|------|------------------------|----------|
| **合起（Closed）** | 第 1 页 | 只显示第 1 页（单页居右竖排，模拟合上的封面）；第 1 页带高亮光晕 |
| **展开-左高亮** | 偶数页（2、4、6…） | 书展开为左右两页；左侧显示选中页并高亮光晕；右侧显示"选中页 + 1"页 |
| **展开-右高亮** | 奇数页（3、5、7…，非第 1 页） | 书展开为左右两页；左侧显示"选中页 - 1"页；右侧显示选中页并高亮光晕 |

**规则**：偶数页在左、奇数页在右（物理顺序，含空白页）。

### 2.3 状态迁移与边界

- **进入状态**：任意时刻选中某一页 → 依据其物理奇偶进入对应状态；状态切换为瞬时动画（翻页过渡，约 200ms，淡入/位移）。
- **翻页方向**：右侧主视图支持鼠标滚轮/方向键/点击左右翻页按钮，每次移动 1 个物理位（对应缩略图列表同步滚动并高亮）。
- **边界**：
  - 选中第 1 页：总是"合起"状态，无左侧页。
  - 选中最后一页（偶数位）：右侧无"选中页+1"，显示空白占位（纸面为空的背面）——直观提示"可补齐末页"。
  - 展开状态左页不存在（理论上不存在，因第 1 页必为合起）。
- **空白页表现**：空白页在书视图中显示为**纯白纸面**，顶部可叠加一个淡色角标（如"空"），无高亮光晕时可显示淡边框示意尺寸。
- **A3 页表现（D2/UI 决策）**：A3 页在书视图中以**横向纸面**展示（超出普通页面宽度时按视图宽度等比缩小），右上角带"折页/横向"角标示意装订后折叠。
- **已旋转标注（问题 3 修改）**：凡"最终旋转角 ≠ 0"的页（含 A3 纵向、A4 横向），在书视图页面左上角叠加淡蓝色"旋 + 方向"角标（如"旋↻90°"），让用户直观看到哪些页被旋转、方向如何。

### 2.4 高亮光晕

- 当前选中页外围绘制柔和光晕（浅蓝渐变，非纯色，避免视觉干扰）。
- 高亮页即为"底部配置面板当前操作对象"；左/右高亮仅标识位置，配置面板始终作用于被高亮的选中页。

## 3. 缩略图列表显示规则（左侧面板）

### 3.1 基本显示

- 按**物理页面顺序**排列（自动插入的空白页同样显示在列表中，见 3.3）。
- 每项：缩略图 + 页号标注（物理序号）+ 标记图标区 + 页码数字预览。
- 缩略图尺寸：固定宽 120px，高按页面纵横比（最大 170px），不足补白；空白页显示纯白方块。
- 滚动：`QScrollArea` 纵向滚动；点击任意缩略图 → 书视图跳转并高亮（状态机随之切换）。

### 3.2 标记图标区（右上角小徽标）

| 标记 | 图标（文字化示意） | 说明 |
|------|-------------------|------|
| 封面 | `封` | 蓝色底 |
| 签字页 | `签` | 橙色底 |
| 不加页码 | `无` | 灰色底（只表示不显示数字） |
| 不占序号 | `弃` | 灰色底 + 斜杠（内容将被丢弃） |
| 从正面开始 | `正` | 绿色底；A3 页该图标置灰且不可点击（只读） |
| 用户自定义标签 | 标签文字 | 黑色小字，仅展示 |
| 空白页 | `空` | 缩略图本身为纯白，加"空"角标 |
| 已旋转 | `旋` | 蓝色虚线底，表示该页将被旋转；悬停/点击显示旋转方向（如"自动检测：顺时针 90°"）（问题 3 修改） |

- 图标为小圆角矩形徽标，不遮挡缩略图主体。
- 同一页可叠加多个徽标（超出宽度时横向排列，最多显示 4 个 + 溢出"+n"）。

### 3.3 空白页与页码预览

- 自动插入的空白页显示在列表中对应物理位置，缩略图为纯白。
- 每项下方显示：
  - 左侧：物理序号（如 `3`）。
  - 右侧：页码数字预览（如 `3`）；无页码的页显示 `—`；"不加页码"显示 `(3)` 示意占位但不显示。
- 底部面板或全局设置修改后，预览实时刷新。

### 3.4 缩略图渲染来源

- 打开阶段：渲染**原页**（PyMuPDF `get_pixmap()`，只读）。
- 规划完成后（含自动插空白/旋转决策后）：重新渲染为"物理顺序 + 旋转 + 空白占位"的预览，供用户确认输出形态（见 7 交互流程步骤 ⑤）。

## 4. 页面配置面板（底部，选中页专属）

选中某一页后，底部面板显示该页设置。分 6 个子区。

### 4.1 页面属性标签（可多选）

- 复选按钮：`封面`、`签字页`、`不加页码`、`不占序号`、`从正面开始`。
- **联动（问题 1 修改）**：勾选"封面"时自动勾选"从正面开始"（可取消）；勾选"签字页"时同理。取消"从正面开始"后该页不再强制从正面开始（A3 页除外）。
- **A3 页的"从正面开始"复选框置灰勾选、不可取消**（只读，需求要点 3-边界）；页面为 A3 时程序自动勾选并禁用。
- 用户自定义标签：输入框 + 添加按钮；仅展示标记，不产生自动行为（可多标签）。
- 修改任一标签 → 立即重算规划（算法 1/2/3）并刷新预览。

### 4.2 页码位置（单页覆盖，优先级高于全局）

| 选项 | 行为 |
|------|------|
| `自动（按物理奇偶）` | 默认：物理奇数页右下角、物理偶数页左下角；A3 页固定右下角（该项对 A3 只读） |
| `右下角` / `左下角` | 强制当前页放右下/左下 |
| `自定义` | 展开两个数值输入框（X 偏移、Y 偏移，单位 mm，相对所选基准角向内为正，D8） |

### 4.3 旋转方向（问题 3 修改）

- **自动检测结果显示**：对需旋转页（A4 横向、A3 纵向），面板显示文字方向检测结论，如"自动检测：顺时针 90°"（或"逆时针 90°"）；无法可靠检测时提示"未检测到文字，默认顺时针 90°，请确认"。
- **旋转方向选项（下拉框）**：`自动检测`（默认）/ `顺时针 90°` / `逆时针 90°` / `不旋转`。
  - 默认值为"自动检测"（即 `rotation_override = auto`，采用 `detected_rotation`）。
  - 用户手动切换后，立即重算该页最终旋转角、页码坐标并刷新预览（书视图/缩略图同步更新"旋"角标）。
  - 用户调整结果保存到配置文件 `rotation_override` 字段。
- 不旋转页（A4 纵向、A3 横向、其他尺寸）该项置灰显示"无需旋转"。

### 4.4 页码样式（单页覆盖，缺省跟随全局）

- 字体：下拉框（默认 Times New Roman）。
- 字号：数值框（默认 9pt 小五）。
- 颜色：取色器（默认黑色）。
- 距右/左边缘：数值框（默认 10mm）。
- 距下边缘：数值框（默认 10mm）。
- 提供"恢复全局样式"按钮。

### 4.5 重叠警告（只读提示条）

- 当算法 5 检测到当前页页码区域与原文内容重叠时，面板顶部显示警示条：
  `⚠ 页码位置可能与原有内容重叠，请调整`
- 黄色背景提示条；**不阻止输出**（可继续，输出后按用户选择保留）。
- 用户调整页码位置/样式后实时重新检测，消除重叠时提示条消失。

### 4.6 起始页码（全局，面板左下角）

- 数值输入框，默认 1，可自定义；修改后重算全部页码数字。

## 5. 全局设置对话框

通过工具栏"全局设置…"打开（模态对话框，`QDialog`）。字段列表：

| 分组 | 字段 | 默认值 | 说明 |
|------|------|--------|------|
| 页码 | 起始页码 | 1 | 全局起始页码 |
| 页码样式 | 字体 | Times New Roman | 全局字体 |
| 页码样式 | 字号 | 9pt | 全局字号（小五） |
| 页码样式 | 颜色 | 黑色 | 全局颜色 |
| 页码样式 | 距右/左边缘 | 10mm | 全局边距 |
| 页码样式 | 距下边缘 | 10mm | 全局边距 |
| 自动识别 | 封面关键词 | 封面 / cover | 逗号分隔，可增删 |
| 自动识别 | 签字关键词 | 签字 / 签名 / signature / sign | 逗号分隔 |
| 自动识别 | 目录关键词 | 目录 / contents | 命中→该页"从正面开始" |
| 自动识别 | 正文关键词 | 正文 / body | 命中→该页"从正面开始" |
| 输出 | 自动补齐末页 | 关 | 勾选后末页奇数位自动补空白 |
| 输出 | 输出后缀 | （打印装订） | 输出文件名后缀 |

- 确定 → 应用并保存配置（写入 `.pagerconfig.json`）；取消 → 不生效。

## 6. 异常提示的 UI 表现

| 场景 | 弹窗类型 | 文案与行为 |
|------|----------|-----------|
| 损坏 PDF | 错误对话框（`QMessageBox.Critical`） | 标题"无法打开"，正文"PDF 文件已损坏，无法打开"；仅"确定"→ 程序退出 |
| 加密 PDF | 输入对话框（`QInputDialog` / 自定义密码框，密码掩码显示） | 正文"该 PDF 已加密，请输入密码"；确认→尝试解密 |
| 密码错误 | 错误对话框 | 正文"密码错误"；按钮"重试 / 退出"；重试→再次输入，退出→程序退出 |
| 空文档（0 页） | 错误对话框 | 正文"PDF 文档无页面"；仅"确定"→ 程序退出 |
| 输出文件已存在 | 信息对话框（`QMessageBox.Warning`） | 正文"输出文件已存在，已跳过"；仅"确定"（不覆盖）；主界面停留当前状态 |

- 所有异常弹窗均为模态；加密输入取消视为用户放弃 → 退出。

## 7. 关键交互流程（文字描述）

### 7.1 打开文件 → 预览

1. 用户点击"打开 PDF…"，选择文件。
2. 加载模块：损坏/加密/空文档检查（异常走第 6 章弹窗流程）；成功则读取页数、每页尺寸、书签。
3. 若存在同名 `.pagerconfig.json` → 恢复上次配置（标记、样式、起始页码、自定义关键词等）。
4. 若配置不可用/无配置：执行"自动识别书签标记"（7.2）。
5. 左侧缩略图列表渲染原页；书视图进入"合起"状态显示第 1 页；底部面板显示第 1 页属性。
6. 自动执行一次规划（算法 1/2/3）并刷新预览——用户看到的是**已按默认规则排好的物理顺序**（含自动空白页与旋转效果）。

### 7.2 自动识别书签标记

1. 工具栏点击"自动识别"（或打开时自动）。
2. 用 PyMuPDF `get_toc()` 读取书签，按全局设置中的关键词（封面/签字/目录/正文 + 自定义）逐条匹配标题（大小写不敏感、包含匹配）。
3. 命中规则：
   - 封面关键词 → 该页**同时标记 `封面` + `从正面开始`**（问题 1 修改：不再用"隐含"措辞）。
   - 签字关键词 → 该页**同时标记 `签字页` + `从正面开始`**（问题 1 修改）。
   - 目录关键词 → 该页标记 `从正面开始`（目录起始页）。
   - 正文关键词 → 该页标记 `从正面开始`（正文第一页）。
   - A3 页自动附加只读"从正面开始"。
4. 自动识别结果以"建议"形式标记（淡色显示），**手工标记优先覆盖**；无书签的 PDF 完全依赖手工标记。

### 7.3 手工标记与调整

1. 在缩略图列表点击某页 → 书视图跳转高亮，底部面板显示该页。
2. 勾选/取消标签（A3 的"从正面开始"只读置灰；勾选"封面/签字页"联动勾选"从正面开始"，可取消）。
3. 调整页码位置/样式/起始页码。
4. **调整旋转方向（问题 3 修改）**：对需旋转页在"旋转方向"下拉框切换 `自动检测 / 顺时针90° / 逆时针90° / 不旋转`；切换后书视图与缩略图立即更新"旋"角标与旋转效果，页码坐标随之重算。
5. 每次变更即时重算并刷新：缩略图顺序与空白页、书视图左右位置与旋转、页码数字与位置、重叠警告条。
6. 变更自动写入配置（防抖 500ms 落盘）。

### 7.4 输出

1. 点击"输出"。
2. 输出模块按 `ProcessPlan` 执行：pikepdf 结构阶段（复制/插空白/旋转）→ PyMuPDF 内容阶段（绘制页码、重叠检测）→ 保存到 `原文件名（打印装订）.pdf`。
3. 若目标文件已存在 → 弹窗"输出文件已存在，已跳过"，不覆盖。
4. 成功 → 提示"输出完成"，可选择"打开所在文件夹"。
5. 全程原文件不被修改（禁止事项检查）。
