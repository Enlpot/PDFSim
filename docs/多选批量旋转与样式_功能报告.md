## 1. 需求

多选批量模式下，**旋转方向**和**页码样式**原被禁用置灰（归入 `_single_page_widgets()`）。用户要求：**多选时可批量调整旋转方向和页码样式**；**页码位置保持不可调**；自定义标签保持不可调。

---

## 2. 实现方案

### 2.1 Controller 层（`src/pdfsim/ui/app_controller.py`）

新增两个批量方法，参照 `set_page_mark_batch` 模式（物理页 → 源页 `original_index` → 覆盖字段，变更后统一 `_after_change()`）：

```python
def set_rotation_override_batch(self, physical_indexes, override) -> None:
    # 空白页旋转由同纸正面页继承、不可手动覆盖 → 跳过
    # 其余选中页 rotation_override 统一为 override

def set_page_style_override_batch(self, physical_indexes, style) -> None:
    # 页码样式对空白页也可设置（空白页有页码也显示样式）→ 不跳过
    # 其余选中页 style_override 统一为 style（None=恢复全局）
```

### 2.2 Config Panel 层（`src/pdfsim/ui/config_panel.py`）

1. **`_single_page_widgets()`** 移除旋转与样式控件，仅保留：页码位置（`_pos_combo` / `_custom_row`）、自定义标签（`_label_input` / `_label_add` / `_labels_display`）。
2. **`_refresh_batch()`** 在禁用单页控件后调用两个新批量回显方法：
   - `_refresh_batch_rotation(pages)`：收集选中页（非空白）的 `rotation_override` —— 全部一致显示该值；有差异显示"自动检测"占位 + 提示"值不一致，将统一覆盖"；**全空白页 → 下拉禁用**（提示"空白页不可调旋转"）。
   - `_refresh_batch_style(pages)`：收集 `style_override` —— 全部一致且非 None 显示该覆盖；否则显示全局样式（控件可选，调整即统一覆盖）。所有样式控件 `setEnabled(True)`。
3. **样式回显抽取** `_apply_style_to_widgets(eff)`：单页 `load_page` 4.4 与批量回显共用，消除重复。
4. **回调增加 `_batch_pages` 分支**（5 个）：`_on_rot_changed` / `_on_style_changed` / `_on_pick_color` / `_on_restore_style` 走批量方法；`_on_vert_pos_changed` 批量时跳过单页边距回显、直接走批量样式更新。
5. **旋转检测标签**：多选时显示批量状态文案（"批量旋转（N 页一致/不一致）"），保持可选；全空白页禁用。

### 2.3 约束落实

- ✅ 页码位置多选仍禁用（`_pos_combo` / `_custom_row` 保留在 `_single_page_widgets()`）
- ✅ 自定义标签多选仍禁用
- ✅ 空白页旋转不可批量覆盖（跳过）
- ✅ 单选路径不变（`_batch_pages` 为 None 时走原单页逻辑）
