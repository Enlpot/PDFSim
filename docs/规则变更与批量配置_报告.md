## 2. 规则变更（任务 1）

### 2.1 变更前后对照

| 维度 | 变更前（旧语义） | 变更后（新语义） |
|------|------------------|------------------|
| "不加页码"（NO_NUMBER） | 保留内容、占序号但不显示数字 | **保留内容、不显示数字、跳过序号**——后续页页码顺延前移 |
| "不占序号"（NO_COUNT） | 原页**替换为空白页**（内容丢弃） | **用户标记路径废除**：不再产生 NO_COUNT_USER 空白页；原页一律保留内容（内容保护铁律） |
| "不占序号"复选框 | 存在，用户可勾选 | **删除**，不再出现在 UI |
| 旧配置中的 `no_count` | — | 加载时**迁移为 `NO_NUMBER`**，按新语义生效 |
| 枚举保留 | — | `PageMark.NO_COUNT` / `BlankPageSource.NO_COUNT_USER` 保留（仅供旧配置迁移 / 序列化兼容） |

示例（提示语 0.1）：页1 显示"1"、页2 不加页码（无数字、序号跳过）、页3 显示"2"——已由测试 `test_no_number_skip_sequence` 精确断言 `["1", None, "2", "3"]`。

### 2.2 用户批准记录

规则变更为用户主动批准方向（提示语 0.1"规则变更说明"），核心约束为**内容保护铁律**：
只允许 添加页码 / 插入空白页 / 旋转页面；禁止删除、修改、覆盖、缩放或移动任何原有内容。原"不占序号"的"原页变空白（丢弃内容）"与该铁律冲突，故废除。

### 2.3 迁移与防御

- 读取路径：`config._page_from_dict` 将 `no_count` 映射为 `NO_NUMBER`（`CONFIG_VERSION` 升到 2；v1 仍可加载并迁移）。
- 引擎路径：`plan_page_numbers` 对残留 `NO_COUNT` 按 `NO_NUMBER` 防御等价（正常迁移后不应出现）。
- `plan_physical_order` **删除 NO_COUNT 替换分支**——所有原页保留内容。
- 验收：`test_old_config_migration`（v1 含 no_count → 迁移生效、原页非空白）与 `test_old_no_number_config_new_semantics`（NO_NUMBER 新语义）通过。

## 3. 空白页可配置（任务 2）

### 3.1 空白页稳定标识方案

每个自动插入的空白页分配稳定标识：

```
blank_id = f"blank:{触发源标识}:{来源类型}"
```

- 触发源标识：来源页 `original_index`（0-based），补齐末页为 `"last"`；
- 来源类型：`BlankPageSource.value`（cover_back / sign_back / push_front / a3_back / fill_last）。

**级联稳定性分析**：空白页标识绑定的是"触发源页 + 来源类型"，而不是物理序号。因此当用户修改其他页标记、触发新的级联插入（如 A3 前的推动空白）导致物理顺序整体重排时，既有空白页的标识**不变**（它们仍属于同一触发源页）。测试 `test_blank_id_stable` 实证：对 A3 混合文档修改第 1 页标记触发级联后，A3 背面空白 `blank_id` 前后一致。

配置键采用 `original_index` 与 `blank_id` 二选一（`PageConfigData.key` 区分 int/str），文件读写支持混合键排序（int 前、str 后）。

### 3.2 配置持久化

- `app_controller._blank_configs: dict[blank_id, set[PageMark]]` 从配置文件提取空白页标记，打开与异步加载后均重建；
- `build_process_plan` 新增 `blank_configs` 参数，在算法 1（物理顺序）之后应用到空白页；
- 保存时 `collect_page_configs(source_pages, plan)` 收集空白页配置（仅 marks 非空才写入），测试 `test_blank_config_persist` 实证保存→重开恢复。

> **空白页用户配置的应用入口**（应审查报告问题 1 补充）：
> 1. **提取**：`app_controller._extract_blank_configs()`（`app_controller.py:217`）在 `open_pdf` 与异步加载完成后调用，把 `page_configs` 中的 **str 键**（`blank_id`）提取为 `self._blank_configs: dict[blank_id, set[PageMark]]`；
> 2. **注入**：`_rebuild_plan` 调用 `engine.build_process_plan(..., blank_configs=self._blank_configs)`（`app_controller.py:411-417`）；`build_process_plan`（`engine.py:508`）在完成物理顺序规划（算法 1）之后、页码规划（算法 2）之前，执行 `engine.py:528-532`——对每个 `p.is_blank and p.blank_id in blank_configs` 的空白页执行 `p.marks.update(blank_configs[p.blank_id])`，把用户显式标记（目前仅 NO_NUMBER）注入该空白页的 `marks`；
> 3. **生效**：`plan_page_numbers`（`engine.py:185`，`engine.py:217` 附近）按 `PageMark.NO_NUMBER in page.marks or user_no_number` 判定——注入后的标记与其他页标记走同一判定路径，用户显式标记优先于来源默认。
>
> 因此空白页配置**应用路径完整**（审查报告问题 1 的猜测 A 成立）：`配置(blank_id) → controller._blank_configs → build_process_plan 注入 marks → plan_page_numbers 判定生效`。`apply_page_configs`（int 键，仅源页）与空白页应用是两条并行路径，互不冲突。

### 3.3 标记覆盖优先级

| 优先级 | 对象 | 规则 |
|--------|------|------|
| 最高 | 空白页用户显式"不加页码" | 覆盖来源默认（无数字 + 跳过序号） |
| 中 | 空白页来源默认 | SIGN_BACK / A3_BACK 默认无页码不占位；COVER_BACK / PUSH_FRONT / FILL_LAST 默认有页码占位 |
| 低 | 源页默认 | 普通页有页码占位；不加页码 → 无数字跳过 |

### 3.4 UI 置灰

空白页选中时：**封面 / 签字页 / 从正面开始**置灰、"从正面开始"不勾选、自定义标签输入与添加禁用；**"不加页码"保持可用**（测试 `test_blank_ui_disabled`）。

## 4. 多选批量（任务 3）

### 4.1 缩略图多选

- `thumbnail_panel` 切为 `ExtendedSelection`（支持 Ctrl / Shift / 拖框多选）；
- 选择变化同步 controller：`selection_set_changed` 信号 → `set_selected_pages`（主选中 = 最小页，驱动书视图状态机）→ `config_panel.on_selection_set_changed`；
- `rebuild` 恢复多选集合高亮（`_updating` 防重入）。

### 4.2 三态复选框

`mark_state_for_pages(pages, mark)` 返回 `True`（全勾）/ `None`（部分）/ `False`（全不勾）。UI 点击行为由代码控制：空 / 半勾 → 添加；全勾 → 移除（禁用 Qt 默认的 Part 循环）。测试 `test_tristate` 覆盖三态。

### 4.3 批量应用

- `set_page_mark_batch`：源页走 `_set_source_mark` 单页链路（A3 取消 FRONT 强制加回、封面/签字联动 FRONT、NO_COUNT→NO_NUMBER 防御），空白页仅 NO_NUMBER 可设、FRONT 跳过；
- 批量后 `rebuild_plan` 级联重算，plan 页数不变（`test_batch_rebuild`）；
- **A3 FRONT 强制不可取消**：批量取消 A3 的"从正面开始"时强制保留（`test_batch_front_forced_a3`）；全 A3 多选时"从正面开始"置灰只读（`test_all_a3_front_disabled`）；
- 混合多选（源页 + 空白页）各自生效（`test_mixed_source_blank_batch`）。

### 4.4 视图与面板联动

- 书视图右上角画 **"已选 N 页"**（多选时）；
- 批量模式下底部**单页设置区（页码位置 / 旋转 / 样式等）置灰禁用**，标签复选框可用（`test_single_page_disabled`）；
- 多选后鼠标点选单页回到单页模式。
