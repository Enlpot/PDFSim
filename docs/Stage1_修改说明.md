## 一、问题 1：封面/签字页"隐含从正面开始"→ 明确为"同时标记从正面开始"

**审查要求（推荐方案 A）**：命中封面/签字关键词 → 同时标记 `FRONT`；`need_front` 保持不变；消除"隐含"措辞；UI 4.1 补充联动交互。

| 文件 | 位置 | 修改内容 |
|------|------|----------|
| 技术方案 | 2.6 `DocumentConfig` 说明块 | 明确"封面/签字关键词命中后，除打上 `COVER`/`SIGNATURE` 外**同时打上 `FRONT`**" |
| 技术方案 | 3.1.2 新增"标记联动"说明段 | 写明自动识别/手工标记两条路径均联动打上 `FRONT`；`need_front` 只检查 `FRONT`（A3 除外），用户取消 `FRONT` 后不再强制从正面开始 |
| 技术方案 | 3.1.2 算法代码内注释 | `need_front` 注释补充联动依据 |
| UI 原型 | 7.2 命中规则 | "封面关键词 → 同时标记 `封面` + `从正面开始`"；"签字关键词 → 同时标记 `签字页` + `从正面开始`"（删除"隐含"措辞） |

**设计要点**：联动使"封面/签字页必须从正面开始"（需求 6.3）在数据层落地为显式 `FRONT` 标记；同时保留 `need_front` 的单一判定（只查 `FRONT`），保证用户取消 `FRONT` 后语义正确（A3 只读除外）。

## 二、问题 2："不占序号"页替换空白时保持原页尺寸

**审查要求**：算法 1 步骤① 中"不占序号"替换取原页尺寸 `(p.width_mm, p.height_mm)`；D5 区分两种场景。

| 文件 | 位置 | 修改内容 |
|------|------|----------|
| 技术方案 | 3.1.1 处理规则映射表 | "不占序号"行尺寸列改为 **"与原页同尺寸"**（原地替换，尺寸不变） |
| 技术方案 | 3.1.2 算法步骤① | `make_blank(size=(p.width_mm, p.height_mm), source=NO_COUNT_USER)`，并注释"保持原页尺寸" |
| 技术方案 | 3.1.2 步骤② | "推正面"空白保持取**前一页**尺寸（D5），并在 3.1.1 表标注"与相邻页（前一页）同尺寸（D5）" |
| 技术方案 | 第 7 章 D5 | 更新为分场景：**"不占序号"替换取原页尺寸**；"推正面"取前一页尺寸 |

**设计要点**：修复"原页为 A3、前一页为 A4"时替换成错误尺寸的问题——原地替换意味着页面槽位不变，尺寸必须等于原页。

## 三、问题 3：旋转方向增加文字方向检测 + 用户确认/调整交互

**审查要求**：算法 3 不再固定顺时针 90°，改为按文字方向自动检测（90°/270°）；UI 标注"已旋转"并提供旋转方向选项；配置增加 `rotation_override`；数据结构增加 `detected_rotation`；测试矩阵增加手动调整场景。

### 3.1 数据结构（技术方案 2.3 / 2.4）

| 变更 | 说明 |
|------|------|
| 新增枚举 `RotationOverride`（`auto` / `cw90` / `ccw90` / `none`） | 2.3 |
| `PageInfo` 新增 `detected_rotation: int` | 文字方向检测结果（0/90/270），算法 3 填充 |
| `PageInfo` 新增 `rotation_override: RotationOverride = AUTO` | 每页旋转方向覆盖 |
| `PageInfo.planned_rotation` 含义更新为"最终旋转角" | 受 `rotation_override` 影响 |

### 3.2 算法 3（技术方案 3.3 整节重写）

- **3.3.1 判定表**：需旋转页（A4 横向、A3 纵向）旋转方向列改为"文字方向检测（90° 或 270°）"；A4 纵向/A3 横向/其他尺寸不旋转。
- **3.3.2 新增"文字方向检测与旋转方向判定"**：用 PyMuPDF `get_text("dict")` 的 block/line `dir` 字段或 `page.get_texttrace()` 提取正文主导基线方向，反推满足"读者逆时针转书 90° 可读"的旋转角；无文字页回退默认 90° 并提示确认。
- **3.3.3 伪代码更新**：新增 `detect_text_rotation()` 与 `final_rotation()`（按 `rotation_override` 决定最终角），`plan_rotation()` 改为输出检测角。

### 3.3 配置文件（技术方案 4.2 / 4.3）

- `pageConfig` 新增字段 `rotation_override`（枚举 `auto/cw90/ccw90/none`，默认 `auto`）。
- 4.3 示例补充展示该字段。

### 3.4 UI（UI 原型说明）

- **2.3**：书视图中最终旋转角 ≠ 0 的页叠加"旋 + 方向"角标。
- **3.2**：缩略图标记图标区新增"已旋转 `旋`"徽标（悬停显示旋转方向）。
- **4.3（新子区）**：页面配置面板增加"旋转方向"——显示自动检测结论（如"自动检测：顺时针 90°"），下拉框 `自动检测 / 顺时针90° / 逆时针90° / 不旋转`，切换后实时重算页码坐标并刷新预览，结果写入配置；不旋转页该项置灰。
- **7.3**：交互流程新增旋转方向调整步骤；原 4.3/4.4/4.5 顺延为 4.4/4.5/4.6（面板改为"分 6 个子区"）。

### 3.5 测试矩阵

- 第 1 节标题改为 **T01–T16**，新增 **T16「用户手动调整旋转方向」**：验证切换 `rotation_override` 后输出 PDF 旋转效果正确更新、页码仍落于目标角、配置保存。
- **T03** 预期行为更新为"按文字方向检测旋转（90° 或 270°）"。
- 第 2 节 2.3 通过标准括注同步为"D1 旋转方向由文字方向检测决定"，验证方法保持不变（方向标记样本 + 逆时针转 90° 可读判定）。
