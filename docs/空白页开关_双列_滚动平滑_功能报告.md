## 功能 1：其他空白页自动编页码开关

### 需求与行为

全局新增开关"其他空白页自动编页码"，默认**关**。只影响两类空白页：

| 空白页类型 | 开关关（默认） | 开关开 |
|-----------|--------------|--------|
| PUSH_FRONT（推正面） | 不显示页码、不占序号、后续顺延 | 显示页码、占序号 |
| FILL_LAST（补齐末页） | 不显示页码、不占序号 | 显示页码、占序号 |
| COVER_BACK / SIGN_BACK / A3_BACK | 不变（来源默认） | 不变 |

优先级：用户显式 NO_NUMBER > 开关 > 来源默认。

### 实现

| 文件 | 改动 |
|------|------|
| `models.py` | `DocumentConfig.auto_number_blank_pages: bool = False`（默认关） |
| `engine.py` | `plan_page_numbers(plan, start_number, auto_number_blank_pages=False)`；关时把 `PUSH_FRONT`/`FILL_LAST` 加入 `no_number_sources`；`build_process_plan` 透传 `config.auto_number_blank_pages` |
| `app_controller.py` | 新增 `set_auto_number_blank_pages(value)`（触发重建+防抖保存） |
| `global_settings.py` | "页码"分组起始页码下方新增复选框"其他空白页自动编页码"（带 tooltip 说明），默认不勾选，accept 时应用 |
| `config.py` | 保存/加载 `global.auto_number_blank_pages`；旧配置无该字段 → 默认 False（**不升级 CONFIG_VERSION**） |

### 测试（专项 8 例）

开关关/开 × PUSH_FRONT、FILL_LAST（含后续顺延）、COVER_BACK/SIGN_BACK/A3_BACK 不变、用户 NO_NUMBER 覆盖、默认关向后兼容、配置保存/加载、旧配置兼容、controller setter、全局设置对话框。

## 功能 2：缩略图双列（宽度自适应）

### 实现

| 文件 | 改动 |
|------|------|
| `thumbnail_panel.py` | 布局改为 `Flow.LeftToRight` + `setWrapping(True)` + `setGridSize(132 × 项高)` + `ResizeMode.Adjust`，列数由 Qt 按视口宽度自动计算 |
| `styles.py` | `LEFT_PANEL_MAX` 320 → **480**（允许拖宽到多列） |

**关键调试发现**：提示语建议的 `Flow.TopToBottom` + wrapping 在 Qt 中**不换行**（实测单列、且滚动条 maximum=0 导致无法滚动）。改用标准相册配置 **`Flow.LeftToRight` + wrapping** 后双列/多列自适应与滚动均正常。这是对指导建议的一处必要修正。

- 拖宽 → 自动双列/多列；拖窄 → 自动回单列（LEFT_PANEL_MIN 200 仍够单列 132px + 滚动条）
- 选中、多选（ExtendedSelection 拖框选）、`scrollToItem(EnsureVisible)` 定位均按 item 索引，与列数无关，无需改动 delegate/rebuild

### 验证（实测 offscreen）

```
面板宽 300 → vp=284 → r2.x=132（双列，列距=grid 宽 132）
面板宽 200 → vp=184 → r2.x=0（单列，第二项在下方）
```

## 功能 3：鼠标滚动平滑

### 实现

`thumbnail_panel.py`：

1. `verticalScrollBar().setSingleStep(20)`（方案 A：滚动条逐格/点击步幅平滑）；
2. 重写 `wheelEvent`（方案 B 兜底，保证滚轮确定平滑）：每格滚轮**固定滚动 24px**（`value - delta*24//120`），不再随视口高度缩放；触控板小步幅（<120）也按比例滚动不吞事件。

- 键盘 PageUp/PageDown 由 QAbstractItemView 处理，不受影响
- `scrollToItem(EnsureVisible)` 定位不受影响

### 验证（实测）

```
scrollbar max=41268（200 页双列/单列均正常滚动）
wheel 一格（delta=-120）→ value 0 → 24px
```
